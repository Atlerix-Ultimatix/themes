# Thèmes communautaires pour Atlas L1

*English below.*

Des thèmes à importer dans **Réglages → Apparence → Thème importé** d'un magasin Atlas L1. Un
thème change l'apparence de l'application, jamais son comportement : il ne lit aucune donnée,
n'envoie rien et ne touche pas au serveur. L'application revérifie chaque fichier à l'import.

Ce dépôt est tenu par la communauté ; il n'est ni tenu ni approuvé par l'éditeur d'Atlas L1. Les
thèmes inspirés d'une œuvre sont des **thèmes de fans non officiels** : leurs images sont
originales, et les œuvres citées appartiennent à leurs titulaires.

- **Installer un thème** : télécharger `themes/<id>/<id>.atlas-theme.json`, puis l'importer dans
  le magasin.
- **Créer un thème** avec un assistant d'IA : lui donner `CONSIGNE-ASSISTANT.md`,
  `gabarit.atlas-theme.json` et `check-theme.mjs`, puis décrire le thème voulu.
- **Vérifier un thème** : `node check-theme.mjs mon-theme.atlas-theme.json` (Node.js 20 ou plus).
- **Proposer un thème** : voir `CONTRIBUER.md`.
- **Signaler un thème** (titulaire de droits) : ouvrir un ticket ; le thème est retiré.

# Community themes for Atlas L1

Themes to import in a shop's **Settings → Appearance → Imported theme**. A theme changes how the
application looks, never what it does: it reads no data, sends nothing and never touches the
server. The application re-checks every file on import.

This repository is run by the community; it is neither run nor endorsed by the publisher of Atlas
L1. Themes inspired by a work are **unofficial fan themes**: their artwork is original, and the
works they mention belong to their owners.

- **Install a theme**: download `themes/<id>/<id>.atlas-theme.json`, then import it in the shop.
- **Create a theme** with an AI assistant: give it `ASSISTANT-BRIEF.en.md`,
  `gabarit.atlas-theme.json` and `check-theme.mjs`, then describe the theme you want.
- **Check a theme**: `node check-theme.mjs my-theme.atlas-theme.json` (Node.js 20 or later).
- **Propose a theme**: see `CONTRIBUER.md`.
- **Report a theme** (rights holder): open an issue; the theme is removed.
